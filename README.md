# Vértice — Finanças pessoais

Aplicação web responsiva para organização financeira pessoal, em português do Brasil.

## Funcionalidades
- Dashboard com saldo, receitas, despesas e taxa de economia.
- Gráfico de fluxo financeiro e distribuição de despesas por categoria.
- Cadastro, busca, edição e exclusão de lançamentos.
- Orçamentos por categoria com acompanhamento de consumo.
- Metas financeiras com atualização de valores guardados.
- Lista de contas recorrentes.
- Preferências e dados demonstrativos locais.

## Desenvolvimento
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Os lançamentos ficam armazenados no localStorage do navegador. Os dados iniciais são demonstrativos e podem ser substituídos pelos lançamentos reais.
